# Homebrew tap for Powerflow macOS27

This tap distributes the Apple Silicon build of [Powerflow macOS27](https://github.com/dashdogy/macOS27).

## Install

```bash
brew install --cask dashdogy/macos27/powerflow-macos27
```

Upgrade with:

```bash
brew upgrade --cask powerflow-macos27
```

Powerflow macOS27 is ad-hoc signed and is not notarized. If macOS blocks the first launch, open **System Settings → Privacy & Security**, choose **Open Anyway**, and confirm the prompt.
